# Search engines and AI assistants

What lets Google, Bing and AI assistants (Claude, ChatGPT, Perplexity, Copilot) read the site and get Me²'s facts right. None of this tries to influence what an assistant recommends: it only makes the site easy to reach, read and quote accurately.

Audited 17 Oct 2026 (two days after the site went public). Recheck on **17 Nov 2026**: search and AI answers take about 30 days to reflect changes.

## In place
- **robots.txt** allows every crawler and points to the sitemap. Generated by `scripts/postbuild.mjs`.
- **Content Signals** in robots.txt (`Content-Signal: search=yes, ai-input=yes, ai-train=yes`, see contentsignals.org): the site may be used for search results, for AI answers that read it live, and for AI training. EC chose all yes on 20 Oct 2026 so assistants can find and recommend Me². They state a preference; they don't block anything. Leave Cloudflare's own "managed robots.txt" (AI Crawl Control) off, because it adds its own Content-Signal lines (by default `ai-train=no`) above ours.
- **Sitemap**: the home page, privacy and the listed careers pages. Thank-you, not-sent, 404 and `/cco/assessment/` pages are `noindex` and left out.
- **Everything is in the HTML**: the copy is in the page as served, so crawlers that don't run JavaScript read all of it.
- **llms.txt**: a plain summary for AI assistants, generated by `scripts/postbuild.mjs` from the config, the flags and `src/content/site.ts`. Its "Common questions" section is the FAQ exactly as the page shows it (same flags), so the terms (start within 2 weeks, 30 days' notice, mistakes fixed at no charge, data never used to train AI) can't drift from the page. It includes "Where is the team based?" and "How quickly will you reply?", as the page does.
- **Structured data** (`src/lib/schema.ts`), all matching visible copy:
  - Home: `Organization` (name, "Me Squared" as alternateName, description from the hero, email, contact point, Phnom Penh as its address while `showLocations` is on, logo, Facebook and LinkedIn), `WebSite` (so search results show "Me²" as the site name, not the domain), one `Service` per offer, and `FAQPage`.
  - Each role page: `JobPosting` (Phnom Penh, full time, from US$600 a month).
- **Titles and descriptions**: one per page in `src/data/routes.json`; one H1 per page; `en-AU`; canonical links.
- **IndexNow**: `npm run indexnow` tells Bing and others the pages changed (key file in `public/`).

## Done
- **Google Search Console and Bing Webmaster Tools** set up, with the sitemap submitted (EC, 19 Oct 2026). `npm run indexnow` run the same day (202 for 6 URLs). Run it again after each live change.
- **Cloudflare's "Block AI bots" setting** checked by EC (19 Oct 2026). Cloudflare can block AI crawlers by their verified addresses, which robots.txt and an outside check can't show, so check it again if assistants stop finding the site.
- **Where Me² is:** "Based in Phnom Penh" (EC, 19 Oct 2026), on the page through `showLocations`.
- **Reply time on the page:** "Usually within 2 hours, evenings and weekends included." (EC, 20 Oct 2026; before that "within 2 hours, day or night"), as a FAQ answer.
- **LinkedIn company page:** links to mesquaredagency.com, uses a description that matches the site and lists Phnom Penh (checked 19 Oct 2026).
