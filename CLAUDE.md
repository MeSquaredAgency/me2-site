# Me² website — standing rules

One-page sales site for Me² (mesquaredagency.com). Primary goal: the visitor clicks **Talk to us** (a mailto to the contact email in v1). BRIEF.md is the full spec; read it before changing anything.

## Where things live (never hardcode them elsewhere)
- Client identity (name, domain, emails, booking URL): `src/config/site.config.ts` only
- Careers (roles, the careers pages and the application form wording): `src/content/careers.ts`; each role also needs its `src/data/routes.json` entry (docs/careers.md).
- Copy and section order: `src/content/site.ts` is the copy of record (v0.15; BRIEF Appendix A still describes v0.14). Don't rewrite copy unless asked; suggest instead.
- Page titles and descriptions: `src/data/routes.json`. Sitemap, robots.txt and llms.txt are generated by `scripts/postbuild.mjs`; never hand-edit `dist/`.
- Design tokens: `src/styles/tokens.css`. Only the text/background pairs in BRIEF §5 are allowed.
- Flags: `src/config/flags.ts`. Never remove a fallback; the site must look complete with every flag off.
- Logo: `src/assets/brand/` (run `npm run brand` after replacing the supplied file).

## Brand rules
- Visible name is always `Me²`. "Me Squared" only in alternateName, aria-labels and mailto subjects. Never ME2, Me2, MeSquared.
- Australian English, sentence case, plain-spoken. Banned words: revolutionary, game-changing, supercharge, seamless, cutting-edge, unlock, guarantee, guaranteed. Grep changed copy before committing.
- Never invent names, testimonials, statistics, results, logos or prices. Never name individuals, except Me² staff who have agreed to it (EC, 21 Oct 2026); Patrick signs the founder note. No industry is presented as "our market" or a client list; kinds of business appear only as clearly labelled use-case examples.
- Stock photos only as credited atmosphere (docs/media.md); no AI-generated people, not even "staff in Me² uniform" (EC asked on 21 Oct 2026; declined: fake staff on a page that sells trust); never stock people as staff or testimonials. Never use the designer's reflected "we" logo concept or the "from me to we." tagline (not approved).
- Sales forms collect contact details and a short task description only. The careers form also takes a CV, work links and a short note (EC, 16 Oct 2026). No form ever has fields for financial, health or identity information.

## Design
Direction: v0.15 "Lit", live since 10 Oct 2026 (BRIEF v0.15 note, DECISIONS.md). Me² runs the back office of established businesses (everything behind the front line: operations, admin, customer service, finance, marketing, social media, paid ads) with trained people backed by AI agents, and designs and builds websites. A Me² person always owns the work; never offer AI on its own. Palette from the logo: deep navy-black (`abyss`), cool paper, coral used as light and the ² only. One typeface, Instrument Sans, set narrow and tight for display (no serif, no all-caps labels). One bold moment: the hero mark, a WebGL glass square with the glowing coral ², whose face is a screen showing the three services (`src/lib/mark-gl.ts`). Hero line: "We run the back office. You run the business." (EC's choice, 14 Oct 2026; don't swap it without asking). People first: Me² is trained people backed by AI agents, never the other way round; every client gets one dedicated Me² person working exclusively for them (EC, 21 Oct 2026; say "working exclusively", never "works for nobody else"); "back end" is not used in copy. The page sells: a "Start here" offer (the whole back office, an extra set of hands, websites), each quoted to the client's requirements with no figures on the page (EC, 16 Oct 2026), and a three-field enquiry form, never a bare mailto. History: sparse type-only was "atrocious"; intelligentoffice-style went live; then "wow", then "Philippe Starck" refinement, then "say what we do on first sight"; then the ivory/serif "Squared" site was "clunky… not good to read", which led to v0.15. EC also said abstract symbolism alone doesn't land ("I understand the square, but that's because I'm the architect"): every signature visual must show the business too. Spend boldness in one place, keep the second half as crafted as the top, say each idea once. Don't add generic card grids, chips, icon wells or gradient text. Mock up one page and get EC's yes before any wider restyle.
Don't give custom styles class names that are Tailwind utilities (ring, shadow, border, container, hidden, fixed, table...). Styles for a class passed into a child component (e.g. EmailLink) must be `:global(...)`.

## Dependencies
Allowed: astro, typescript, @astrojs/check, tailwindcss, @tailwindcss/vite, @fontsource-variable/instrument-sans, @fontsource/instrument-serif, sharp; dev: @playwright/test, @axe-core/playwright, lighthouse, linkinator, wrangler; Phase 2: resend. Anything else needs a line in DECISIONS.md.
Out of scope: CMS, auth, database, client-side routing, UI frameworks, animation/icon libraries, carousels, chat widgets, cookie banners, newsletter signup, Google Fonts CDN, third-party scripts.

## Git and deploys
- **Public since 15 Oct 2026**: EC removed the Cloudflare Access sign-in (private 10–15 Oct), so the live site and previews can be fetched and checked directly; previews send `X-Robots-Tag: noindex` but anyone with the link can open them. See DEPLOY.md.
- **Live since 9 Oct 2026** at https://mesquaredagency.com: Cloudflare Workers project `mesquared` in the **Me²** account (`wrangler.jsonc`, `worker/index.ts`). See DEPLOY.md.
- Code lives on GitHub at **MeSquaredAgency/me2-site** (private). A GitHub Actions workflow (`.github/workflows/publish.yml`) publishes it to the Me² Cloudflare account: **pushing or merging to `main` puts it live**; pushing any other branch makes a preview URL (in the run summary). Not Cloudflare Workers Builds: the MeSquaredAgency org is linked to the APN Cloudflare account (APNRE site), so don't re-point it. Never push or merge to `main` without EC's explicit yes for that change. `main` must always equal what's live.
- `npx wrangler deploy` (the by-hand fallback) also publishes immediately; same rule. For a look first, push a branch or use `npx wrangler versions upload`.
- Never publish from the APN Real Estate Cloudflare account; `account_id` in `wrangler.jsonc` pins the Me² account.
- Don't edit the DNS records for `mesquaredagency.com` / `www` (the Workers custom domains own them) or touch MX/TXT (Google Workspace email).
- Branch for every change. Run `git branch --show-current` right before every commit and push; other sessions may share this checkout.
- Plain-English commit messages: what changed for the visitor, then why.
- Ask EC before merging, deploying, DNS changes, or anything that emails real people.
